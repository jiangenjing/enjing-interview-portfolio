# 蒋恩晶 · AI 产品解决方案面试作品集

在线浏览：[打开面试作品集](https://jiangenjing.github.io/enjing-interview-portfolio/)。

发布版 `index.html` 使用本地图片资源以支持按需加载和缓存。离线请下载 `offline.html`，该文件内嵌全部样式、脚本与图片，可单独打开；外部 GitHub、论文和在线 Demo 链接需要联网。

## 展示结构
1. 四个工作特质与经历佐证：技术背景、产品思维、数理思维、坚韧自驱
2. 四个重点案例：围绕四个特质，梳理问题、个人职责、作品产出、能力佐证与复盘
3. OntoCare：双本体、服务链路、真实截图、历史评测、个人贡献与智能服务赛道冠军证书（支持放大）
4. Deep Research：依据简历绘制的多 Agent 架构及评测记录
5. 壳牌 AI 能源大脑：交互原型、方案架构、商业化与团队协作
6. 追觅实习：产品原图、市场研究、用户分析和 GTM 商业测算
7. 三篇论文：正式中英文标题、完整中文摘要、方法示意与个人贡献
8. 教育、技能、语言、证书、竞赛及研究中的硕士课题
9. 与 Data AML / 火山方舟岗位工作的关联
10. 八段约 100 字经历概述：四个重点案例、三个补充作品及硕士在研课题，标注主要对应特质

## 岗位理解子页面
- `role-understanding.html`：岗位分层示意、可切换客户支持流程、四个官方公开合作案例、能力与经历对应。
- 客户案例保留披露时间与原文链接，个人观察与公开事实分别标注。
- 主页面顶部导航、首屏与岗位关联区均提供入口。单文件离线版中的子页面入口指向在线地址。

## 交互
- 特质卡片可跳转到对应项目与证据选项卡。
- 项目默认展示“项目复盘”：左侧作品，右侧推进过程；原有架构、截图、评测和工作内容继续保留。
- 图片点击后可放大，按 Esc 关闭。
- 顶部 A− / A+ 可调整正文大小并记住选择。

## 内容口径
- 根据 2026-10-20 版本的个人简历与目标岗位 JD 整理；四个特质中的兴趣、量化自我与现场复盘由本人补充。
- 现有项目截图为公开仓库原图，来源记录在 asset-sources.json。
- 架构图为根据简历与对应仓库重绘的 SVG，原图位于 assets/。
- Deep Research 当前没有公开仓库，架构与抽样评测按简历口径展示。
- 中文摘要依据两篇本地论文原文及 PLOS ONE 公开原文翻译，每篇提供 DOI 原文链接；中文标题标注为译名。
- 论文作者次序参考项目仓库已核对的发表材料；学生作者次序与期刊署名分别说明。
- 本作品集展示公开项目材料与个人履历，原始简历 PDF 不在仓库中。
